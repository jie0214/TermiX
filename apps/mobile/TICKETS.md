## 第 2 張：單一 SSH 密碼連線

前置依賴：第 1 張。

- 點選已保存的主機，使用 Keychain／Keystore 保存的密碼連到真實 SSH 終端。
- 顯示目前主機、位址與連線狀態；可輸入與中斷。
- 全 App 最多一個 SSH session，包含連線途中。切換目標前確認中斷，不暗中保留舊 session。
- 首次連線核對 SHA-256 指紋後才送出認證，記住公鑰；已知金鑰不符則阻擋，不提供略過驗證。
- 使用原生輸入鍵盤；鍵盤展開後終端與輸入區可見，更新遠端 PTY 尺寸。
- 密碼不進入 WebView、一般資料庫、日誌與終端輸出事件。終端僅顯示真實遠端輸出，不保存歷史到磁碟。
- 取消、連線錯誤、錯誤密碼、拒絕指紋、金鑰變更與背景／恢復不能留下假連線狀態。
- 測試邊界延續先前方案：使用者畫面流程與外部 SSH／機密儲存邊界，加真實 SSH 協定整合測試；真機驗收狀態須如實記錄。

本票以原生輸入區逐次送出文字與 Enter；快捷控制鍵、方向鍵與常用指令屬第 4 張。私鑰連線屬第 3 張，不因已有設定欄位宣稱可用。沒有自動重連或背景保持連線承諾；進入背景主動中斷，回來可重新連線。

## 第 3 張：SSH 私鑰登入

前置依賴：第 2 張。

- 延用系統檔案選擇器匯入私鑰、選填 passphrase，分離保存於安全儲存並實際登入。
- 支援 OpenSSH RSA／Ed25519／ECDSA（未加密與密語加密）、PEM RSA PKCS#1／ECDSA SEC1，以及未加密的 PKCS#8 RSA／Ed25519／ECDSA；另支援 Go SSH 函式庫可解密的傳統加密 RSA／EC PEM。
- 加密 PKCS#8、DSA、硬體金鑰等未支援的格式或參數不可靜默略過。毀損私鑰、缺少密語、解密失敗及遠端不接受公鑰須有可理解的訊息。
- 缺少或錯誤密語可在終端錯誤畫面修正，安全保存後重試；保存失敗不重新連線，不把密語寫入一般設定。
- 私鑰不進入終端 WebView、日誌、狀態快照或同步；原生錯誤僅回固定代碼。匯入後清除 App 快取副本，不移除使用者原始檔。
- 沿用主機金鑰驗證、單一 session 與背景中斷；私鑰模式不得退回密碼或把密語當登入密碼送出。
- 真實 SSH 整合測試涵蓋成功與失敗；iOS 原生驗收涵蓋匯入、錯誤密語修正、登入與重開。實體手機與 Android 狀態如實記錄。

## 第 4 張：終端快捷鍵與常用指令

前置依賴：第 2 張。

- 已連線終端提供單一小按鈕，點擊後彈出可捲動的快捷面板；可關閉、重開，斷線時移除。
- 提供 Ctrl+C、Ctrl+D、Ctrl+L、Esc、Tab、上下左右方向鍵，透過既有 SSH session 傳送真實控制碼。
- 延用逐次輸入模式：Tab／方向鍵等會先送出尚未提交的文字；Ctrl+C 丟棄本機草稿並送中斷碼。面板可連續操作，Enter 由既有「送出」提供。
- 設定頁提供 SSH 常用指令管理，可新增名稱與單行指令、確認刪除；失敗保留輸入與既有資料並提供重試。
- 常用指令選取後先填入終端輸入框，由使用者按送出執行；已有草稿時先確認取代，避免誤執行或遺失草稿。
- 指令內容可能含敏感資料，全份指令集使用既有 Keychain／Keystore 安全儲存，不進一般 SQLite、日誌或同步；重開可讀回。
- 名稱最多 80 字元，指令最多 4093 字元且不接受換行或控制碼；最多 50 筆、序列化總長度最多 64000 字元，為控制碼保留傳送空間。
- 驗收包含設定新增／刪除／重開、面板開關、常用指令不自動執行、控制碼與輸入順序、儲存失敗及斷線；原生裝置驗證狀態如實記錄。

快捷操作後若遠端可能仍有未提交輸入，選取常用指令會先詢問是否傳送 Ctrl+C，再填入指令；不默認遠端輸入已清空。

## 第 5 張：匯入 kubeconfig 並查看 Pod

前置依賴：手機版外殼與設定頁。

- 在設定透過系統檔案選擇器匯入 256 KB 內的 kubeconfig；解析目前 context、對應叢集、使用者及預設 namespace，成功後可在 Kubernetes 分頁查看 Pod。
- 本票支援內嵌 Bearer token、HTTPS 系統信任根或內嵌 `certificate-authority-data`；拒絕 HTTP、`insecure-skip-tls-verify`、檔案參照、exec／auth-provider、用戶端憑證及其他尚未實作的驗證方式，沒有降低 TLS 驗證的選項。
- 以目前 context 的 namespace 開始，允許輸入其他合法 namespace；按「查看 Pod」才讀取。顯示名稱、階段與就緒容器數；單次最多顯示 200 筆，若 API 提供續頁則顯示截斷提示。唯讀，不修改叢集。
- 401、403、連線／TLS 失敗與無效回應需顯示明確、安全的訊息，不把 token、完整 kubeconfig 或原生錯誤寫入畫面、日誌或一般狀態。
- kubeconfig 以 AES-256-GCM 加密於 App 私有文件檔，金鑰與檔案參照保存於 Keychain／Keystore；匯入暫存檔讀取後刪除。匯入失敗保留舊設定；重新開啟仍可讀取。
- Native client 不跟隨重新導向轉送 token，驗證 CA，限制連線時間與回應大小；namespace 變更時舊查詢不得覆蓋畫面。
- 實體裝置與 Android 原生建置驗收狀態如實記錄。第 6 張才支援用戶端憑證登入；後續票再加入其他資源、Log、縮放與資源用量。

## 第 6 張：Kubernetes 用戶端憑證登入

前置依賴：第 5 張。

- 延用設定頁匯入、目前 context 與查看 Pod 流程，支援 base64 內嵌 PEM `client-certificate-data` 與未加密 `client-key-data`，透過雙向 TLS 登入。
- 匯入及連線前檢查憑證／私鑰完整性、格式、配對與憑證鏈日期；缺漏、毀損、不匹配、過期及尚未生效均提供固定安全訊息。加密私鑰不支援。
- 同時提供 token 與用戶端憑證時拒絕歧義設定；憑證模式不送 Bearer header，也不退回其他登入方式。
- 保留伺服器 CA／主機名稱驗證及既有 HTTPS 限制，不支援外部檔案參照、exec 或略過 TLS 驗證。
- 完整 kubeconfig 沿用 AES-GCM 與 Keychain／Keystore 保存，私鑰不進一般狀態、日誌或同步；匯入失敗保留舊設定。
- 驗收包含真實 mTLS 成功與不可信用戶端拒絕、錯誤提示、既有 token 回歸及 iOS 原生建置；實際裝置與 Android 未驗證項目如實記錄。

## 第 7 張：查看工作負載與 ConfigMap

前置依賴：第 5、6 張。

- Kubernetes 分頁提供 Pod、Deployment、StatefulSet、ConfigMap 分類，沿用目前 context、namespace 輸入及手動查詢；切換分類／namespace 時移除舊結果。
- Deployment、StatefulSet 顯示名稱、就緒／期望副本數及已更新副本數；保留 0 副本語意，不以缺少 status 宣稱已就緒。
- ConfigMap 清單顯示名稱、項目數及 immutable 狀態；點選後用獨立面板查看文字內容，binaryData 僅顯示位元組數，不下載或執行內容。
- 清單至多 200 筆並提示續頁截斷；明細最多 200 個項目、每項 4096 個 Unicode 字元、合計 32768 個字元，有截斷提示。回應大小維持 2 MB 上限。
- 明細可關閉及失敗重試。關閉、切換分類／namespace、重新查詢、匯入設定及 App 進入背景時清除內容；過期的非同步回應不得重新顯示。內容不存入磁碟、日誌或同步。
- 只發送 GET，沿用 token／mTLS、CA 驗證、不跟隨重新導向與逾時；401／403／404、無效回應及空清單需提供安全且可理解的狀態，不影響其他資源分類查詢。
- 保留既有 Pod 行為；Log、縮放與資源用量分屬第 8 至 10 張。本票不新增 Secret、編輯、刪除或完整 Kubernetes client。
- 驗證涵蓋真實 HTTPS、原生橋接、使用者切換／明細流程與失敗競態；iOS、Android 及實體裝置驗收限制如實列出。

API 欄位依據：[Deployment](https://kubernetes.io/docs/reference/kubernetes-api/apps/deployment-v1/)、[ConfigMap](https://kubernetes.io/docs/reference/kubernetes-api/core/config-map-v1/) 官方文件。

## 第 8 張：查看容器 Log

前置依賴：第 5 至 7 張。

- 點選 Pod 開啟獨立 Log 面板，重新讀取該 Pod 的一般、初始化與臨時容器；預選第一個容器，允許明確切換。容器查詢失敗可重試。
- 預設查看目前執行紀錄，可切換前次已終止容器的紀錄；切換後自動讀取，也可手動重新整理。不是持續串流，不自動輪詢。
- 使用 Kubernetes Pod log GET API，指定 container、previous、timestamps=true、tailLines=200、limitBytes=65536、follow=false；本機同時限制回應讀取量與最多 200 行，達位元組上限或本機截斷時提示內容可能不完整。
- 以可選取的純文字顯示，保留換行；不以 WebView／終端模擬器解譯內容。無效 UTF-8 使用替代字元，空回應顯示沒有紀錄。
- 切換容器／目前與前次紀錄／重新整理時立即清除舊內容。關閉、切換資源或 namespace、重新查詢、匯入設定、App 背景及卸載畫面時清除 Log；延遲回應不得讓已關閉或切換的內容復活。
- Log 只保存在當次記憶體，不寫入磁碟、日誌、同步或主機設定；沒有下載、分享、剪貼簿自動寫入功能。
- 沿用 token／mTLS、伺服器驗證、拒絕 redirect 及逾時。400（尚未啟動或沒有前次紀錄）、401、403、404、連線與 API 失敗使用固定安全訊息，不呈現伺服器錯誤內容。
- 驗收涵蓋真實 HTTPS 參數、大小／行數／UTF-8、容器及 namespace 驗證、權限錯誤、空紀錄、重試、容器切換及關閉競態；原生 iOS 操作與其他平台限制如實記錄。

API 依據：[Kubernetes Pod API](https://kubernetes.io/docs/reference/kubernetes-api/core/pod-v1/)。

## 第 9 張：調整工作負載副本數

前置依賴：第 7 張。

- 點選 Deployment／StatefulSet 開啟副本設定，先 GET apps/v1 的 scale 子資源，取得目前期望副本數、UID 與 resourceVersion；不使用清單快取作為寫入條件。
- 輸入 0 至 2147483647 的整數；送出前顯示叢集、context、namespace、種類、名稱與目前／新副本數，由使用者明確確認。0 副本提示停止所有副本；相同副本數不送出。
- 僅 PUT scale 子資源，使用 autoscaling/v1 Scale 與已讀取的 UID／resourceVersion，避免覆蓋同時發生的變更或同名重建資源。沿用 token／mTLS、CA 驗證、拒絕 redirect、12 秒逾時與回應上限。
- 每次確認最多送出一次；送出期間禁止重複送出、切換查詢目標或匯入設定。關閉／背景或變更目標清除待確認操作；已送出的變更不宣稱可以取消。
- 409 衝突要求重新讀取再確認；401／403／404／422 與其他拒絕提供安全錯誤。傳輸失敗或無法驗證成功回應時標示結果未確認，不自動重送，必須先重新讀取。
- 成功僅表示 API 接受期望副本數，不代表 Pod 已就緒；移除舊清單並允許重新查詢。關閉後仍保留本次結果提示，延遲回應不得重新開啟面板。設定與操作內容不新增磁碟／日誌／同步儲存。
- 支援手動縮放，不管理 HPA；確認面板提醒自動縮放或其他工具可能再次調整副本數。本票不加入刪除、完整編輯、Secret 或 metrics。
- 驗收涵蓋真實 HTTPS GET／PUT、更新條件、0 副本、非法輸入、權限與衝突、未確認結果、不重送及關閉競態；iOS 原生驗收與 Android／實體裝置限制如實記錄。

API 依據：[Deployment scale](https://kubernetes.io/docs/reference/kubernetes-api/apps/deployment-v1/)、[StatefulSet scale](https://kubernetes.io/docs/reference/kubernetes-api/workload-resources/stateful-set-v1/)。

## 第 10 張：查看簡易資源用量

前置依賴：第 5 至 8 張。

- 在 Pod 清單提供「用量」入口，開啟獨立面板；查詢目前 namespace 的指定 Pod，保留既有 Log 操作。開啟時讀取，可手動更新，不輪詢。
- 使用 metrics.k8s.io/v1beta1 的 PodMetrics GET API，顯示已回報容器 CPU／記憶體合計及各容器數值。CPU 使用 m（1000 m = 1 核心），記憶體使用 MiB；不要求節點查詢權限，也不推算叢集／工作負載總量或使用百分比。
- 顯示 API 採樣時間（UTC）及 window 秒數，說明 CPU 是區間平均值、記憶體是 working set、非即時資料且不包含未回報容器；沒有歷史圖表、requests／limits 比較或告警。
- 解析有界、非負的 Kubernetes Quantity，支援 n／u／m、decimal SI、binary SI 與科學記號。缺少、非法、負數、非有限值、溢位／下溢不得當作 0。顯示最多小數 2 位，正數低於 0.01 顯示 <0.01，真正 0 保留 0。
- 404 或空容器清單提示該 Pod 尚無資料或叢集未提供 Metrics API；503 提示用量服務暫不可用；401／403、格式錯誤及連線失敗使用固定安全訊息，不洩漏伺服器錯誤內容。失敗可重試且不保留上一筆數值。
- 沿用 HTTPS CA／token／mTLS、拒絕 redirect、12 秒逾時；回應最多 2 MB、200 個容器。檢查 Pod／namespace 身分、容器名稱與唯一性、採樣時間及正數 window；無法驗證時不顯示猜測數值。
- 用量只存記憶體；關閉、背景、卸載畫面、切換分類／namespace、重新查詢及匯入設定後清除，延遲回應不能復活。不中斷既有 Log、縮放及唯讀資源操作。
- 驗證涵蓋真實 HTTPS、單位換算與合計、零／極小值、缺失與服務不可用、重試、關閉與切換競態及原生 iOS 操作；Android／實體手機驗收限制如實列出。

API 依據：[Resource metrics pipeline](https://v1-36.docs.kubernetes.io/docs/tasks/debug/debug-cluster/resource-metrics-pipeline/)、[Quantity](https://kubernetes.io/docs/reference/kubernetes-api/definitions/quantity-resource/)。本票採用廣泛部署的 v1beta1；僅提供 v1 的叢集尚未支援。


## 第 11 張：桌面設定同步到 iPhone

使用者選定同時支援 CloudKit 與檔案模式，由使用者選擇。

- 桌面提供手機設定匯出及 CloudKit 自動上傳開關；手機設定提供關閉、CloudKit、檔案匯入。
- 僅同步主機名稱、位址、連接埠、使用者名稱及穩定識別碼。不包含密碼、私鑰、token、機密參照、腳本、常用指令、kubeconfig 或信任金鑰。
- 兩種方式使用同一版格式，整份驗證再原子保存；最多 500 台、256 KB。重複匯入冪等，保留手機自行新增的主機，不同步刪除。
- 檔案透過系統選擇器匯入，先確認筆數再套用；取消、無效格式或儲存失敗不破壞舊設定，清除 App 匯入暫存副本。
- CloudKit 使用同 Apple ID 的 private database；桌面開啟及手機位於前景時每 30 秒更新，手機可立即同步。SSH 連線期間暫停套用，不承諾背景常駐或推播。
- 切換模式及進入背景後丟棄尚未套用的舊回應；未設定容器、未登入、無資料或網路失敗需真實提示，不能回報假成功。
- 同步主機可在手機補上密碼／私鑰。目標改變時停用舊憑證，舊終端畫面不能把新憑證送至舊目標。
- 原生差異集中於接入層；Android 保留檔案模式，CloudKit 顯示不支援。
- CloudKit 真實跨裝置驗收需正式容器與 Apple 簽章；可建置、mock 測試與尚待簽章的驗證狀態分別記錄。細節見 SYNC.md。

## 第 12 張：語言切換與保存
