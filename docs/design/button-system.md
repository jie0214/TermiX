# 共用按鈕規格

所有應用程式按鈕使用 `ui-button`，外觀由 `frontend/src/components/controls/button-system.css` 集中管理；頁面只設定排列、必要寬度與功能狀態。新增按鈕時不得另寫背景、圓角、字級或陰影。

| 類型 | 修飾 class | 使用情境 |
| --- | --- | --- |
| 主要 | `ui-button--primary` | 新增、儲存、執行、套用 |
| 次要 | `ui-button--secondary` | 取消、返回、瀏覽檔案 |
| 低強調 | `ui-button--quiet` | 選單入口、複製、重新整理 |
| 危險 | `ui-button--danger` | 刪除、清空、停止服務 |
| 分頁 | `ui-button--tab` | 頁面導覽、設定、工作區與資源詳情 |
| 選擇 | `ui-button--choice` | 主題、縮放比例、排列模式 |
| 選單項目 | `ui-button--menu` | 下拉選單內的操作 |
| 業務狀態 | `ui-button--state` | 自訂 SwitchBox 狀態，保留使用者的狀態配色 |

純圖示操作另加 `ui-button--icon`，密集資料列或分頁關閉按鈕另加 `ui-button--compact`。不得將帶有可見文字的按鈕設為圖示型。

一般按鈕最小高度為 34 px、圓角為 8 px、字級為 13 px；密集圖示按鈕為 24 px。主要動作使用明暗主題對應的中性實色，危險動作使用語意紅色。

選取狀態由 `.active`、`.selected` 或既有 ARIA 狀態驅動。停用狀態保留原有功能限制，鍵盤焦點必須可見，並尊重減少動態效果偏好。樣式不取代原有事件、確認流程或權限檢查。

macOS 視窗紅黃綠控制鈕保留原生外觀。主題預覽色票與自訂狀態顏色保留其功能意義，但按鈕尺寸與互動外觀仍使用共用規格。

既有模組有高特異度樣式，共用檔案集中使用 `!important` 作為過渡邊界；新頁面不得藉由增加特異度或內嵌樣式覆蓋共用規格。

管理頁面將相關操作合併為下拉選單：新增類操作使用「新增」，排列與排序使用「檢視」，匯入、匯出及次要管理操作使用「更多」。單一新增、重新整理與表單提交保留直接入口；危險選項保留語意紅色及既有確認流程。

選單共用 `components/controls/dropdown.js`，支援方向鍵、Home／End、Escape、外部點擊及焦點離開時關閉。每次重繪與元件移除均解除舊監聽，父元件不重複綁定子元件選單。

管理頁的操作列共用 `vault-commandbar`：搜尋在左、操作在右，無搜尋時操作仍靠右；新增使用加號與文字，檢視使用調整圖示，更多使用省略號。頁面內距統一為 28 px，窄視窗為 20 px。

新增與編輯表單共用右側 `vault-drawer`，一般寬度為 380 px，較窄視窗為 340 px，820 px 以下靠工作區右側覆蓋呈現。標題、內容及底部操作列共用內距；關閉的面板不可取得鍵盤焦點。金鑰表單沿用相同位置，取消後將焦點交回新增入口。
